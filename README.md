# -Nova-Mart-Marketing-Consulting
Sales Performance and Marketing Analytics Dashboard using power BI

Nova Mart Marketing Consulting is a data visualization and business intelligence project developed using Microsoft Power BI. The project analyzes sales performance, revenue trends, product performance, and market insights through interactive dashboards and visual reports. It transforms raw sales data into meaningful insights using charts, graphs, key performance indicators (KPIs), and filters. The dashboard helps businesses monitor performance, identify trends, and make informed, data-driven decisions to improve sales and marketing strategies.
